feat(css): layer the library stylesheet and drop the `@scope` dependency

The published stylesheet declares two cascade layers, `pagopa-ui.base` and
`pagopa-ui.utilities`, instead of wrapping every rule in `@scope
(.pagopa-ui-root)`: a browser that does not support `@scope` now renders the
library instead of dropping it, and a host can order its own layers against
the library. The resets reach only the roots the library renders — every
component root carries `data-slot`, overlays mount into
`[data-pagopa-ui-portal-root]` — so legacy host markup inside a `UIProvider`
keeps the browser's defaults. The artifact contains no `@scope` at-rule.
