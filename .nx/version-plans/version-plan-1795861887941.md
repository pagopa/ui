feat(icons): render the subpath icon exports through the `Icon` shell

`@pagopa/ui/icons/<slug>` resolved straight to the generated module, so an
import from it shipped a bare `svg`: no `.pagopa-icon` class for consumer CSS
to exempt, no decorative default, and `size`/`aria-*` ignored. Each generated
module now exports the drawing the registry hands to `Icon` (`variants`, keyed
by source node id) and the same drawing inside that shell, so the subpath
import and `PagoPAIcon` render the same markup and cannot drift.
`GlyphProps` is the published surface: `Icon`'s props without the drawing.
