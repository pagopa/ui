## Open risks

- The check sees string, template-literal and template-returning arrow defaults.
  Three Italian defaults stay in components because their syntax is outside it:
  `selectionHint` in `DragAndDrop` (a conditional-bodied arrow) and the
  `emptyState = { title: "Nessun risultato" }` object default in `Table` and
  `TableList`. They remain overridable props; a follow-up could extend the check.
- `Messages.stepper.stepLabel` takes the resolved status-label function as a
  second argument. That keeps an overridden `statusLabel` visible inside the
  default `stepLabel`; a self-contained dictionary function would have silently
  dropped the caller's phrase from the announcement.
- The worktree's base predates the merges of actions 01, 06 and 09 on `main`;
  the merge may need conflict resolution in stories or components, and the
  accessibility contract those actions add has not run against the new stories
  here.
